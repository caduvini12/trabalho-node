# trabalho-node

Sistema de lanchonete com 3 servidores (precisa do Node 18 ou mais novo).

## Como rodar

1. `npm install`
2. Abra 3 terminais e rode um comando em cada:
   - `npm run start:3`  (estoque, porta 3002)
   - `npm run start:2`  (pedidos, porta 3001)
   - `npm run start:1`  (paginas, porta 3000)
3. Abra http://localhost:3000
